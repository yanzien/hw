# 暑假作业清单 · 任务管理 Web

一个零依赖、纯前端的暑假作业规划小工具：按科目分项管理作业、勾选完成、调配到具体日期、批量操作、自动分配、多项目隔离、日历调度，支持本地保存、导出备份、生成只读分享链接，并可接入云端实现多设备同步。

> 部署后在 `https://<你的用户名>.github.io/<仓库名>/` 访问。

## 功能特性

- **分项管理**：按「科目 → 类别」组织作业，可添加自定义内容（填「共有几项」自动生成 N 条相同内容）。
- **完成 / 调配**：勾选即标记完成并移入「已完成」区；可把任务安排到具体日期。
- **批量操作**：勾选多条后统一改截止日期、调配日期、复杂度、标记完成/未完成、删除。
- **自动分配**：综合优先级科目、截止日期、任务复杂度（1–100），用最小负载算法让每天负担尽量均衡；支持「默认 / 复杂度低优先 / 复杂度高优先」三种模式；可标记任务「不参与自动调配」。
- **多项目隔离**：右键项目名可复制 / 重命名 / 删除；每个项目互不干扰。
- **日历调度模式**：左侧任务列表 + 右侧月历，点任务再点日期即调度；点分组名 / 多选可批量顺延分配；可取消某日全部任务。
- **进度与提醒**：顶部总进度、按科目进度、按截止日期排序与逾期提醒。
- **撤回 / 复原**：按钮 + Ctrl+Z / Ctrl+Y，整步快照。
- **深浅色主题**：一键切换，偏好本地保存。
- **本地保存**：所有数据存浏览器 `localStorage`，按登录凭据号隔离；可导出 / 导入 JSON 备份。
- **分享链接**：生成只读 URL，家人免登录查看进度（无法修改）。
- **小后台**：密码进入后可改公告、介绍、关于作者、更新日志、默认数据、日历帮助（均支持 Markdown）。
- **移动端优化**：响应式布局，手机访问自适应。

## 仓库文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 网站本体（自包含，无需联网即可用） |
| `site-config.json` | 站点配置（公告 / 介绍 / 关于 / 更新日志 / 默认数据 / 同步端点等），后台「导出」可覆盖它 |
| `README.md` | 本说明 |
| `sync-worker.js` | 可选云端同步后端代码（Cloudflare Worker） |
| `wrangler.toml` | 后端部署配置模板（可选） |
| `云端同步部署指南.md` | 后端部署详细步骤（可选） |
| `.nojekyll` | 可选：禁用 GitHub Pages 的 Jekyll 处理（本项目非必需，见下） |

## 快速本地预览

直接双击 `index.html` 即可（后台密码哈希已用纯 JS 实现，`file://` 也能进后台）。或起一个本地服务：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

## 部署到 GitHub Pages

1. 把 `index.html`、`site-config.json`（以及本 README）放到仓库**根目录**。
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支 / `root` 目录，保存。
3. 几分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

> **关于 `.nojekyll`**：本项目只有 `.html` 和 `.json`，GitHub Pages 默认 Jekyll 处理不会破坏它们，因此**可不加 `.nojekyll`**。若日后加入以 `_` 开头的文件，再补一个空文件 `.nojekyll` 即可（在 GitHub 网页 Add file → Create new file 直接手打文件名创建，Windows 拖拽上传会跳过隐藏的点文件）。

## 可选：云端同步（多设备）

不配置也完全可用（本地保存 + 分享链接）。要跨设备自动同步，按 `云端同步部署指南.md` 部署一个 Cloudflare Worker（免费），把它的地址填进 `site-config.json` 的 `syncEndpoint`（设了 `SYNC_KEY` 则前端 `syncKey` 填相同值），重新推送即可。不同设备用**同一凭据号**登录即自动同步。

## 小后台

点页面顶部 🔧，输入密码进入。默认密码 **`admin123`**（存的是 SHA-256 哈希，可在 `site-config.json` 里改哈希值）。后台可改公告 / 介绍 / 关于作者 / 更新日志 / 默认数据 / 日历帮助，支持 Markdown；「导出 site-config.json」放到仓库根目录即正式发布。
