📖 使用说明

  • 项目：顶部标签切换；右键项目名可「重命名 / 复制 / 删除」。
  • 添加：「共有 N 项」生成 N 条相同内容；不填日期默认 2026/8/31。
  • 完成：勾选框标记完成，移入「已完成」。
  • 编辑 / 复杂度 / 不调配：点「编辑」可改内容、日期、调配，并设置复杂度（1-100，默认 50）与「不调配」。
  • 提醒：逾期 / 今天 / 3 天内到期自动打标签。
  • 进度：总进度 + 按科目进度。
  • 排序：「按截止日期排序」截止靠前排前。
  • 自动分配：默认 / 复杂度低优先 / 高优先三种模式，均保持每日复杂度均衡；可设优先级科目、排除不调配。
  • 每日任务：显示当天完成数与总复杂度。
  • 批量：统一改截止日期 / 调配 / 复杂度 / 完成 / 删除。
  • 撤回/复原：↶ ↷ 按钮或 Ctrl+Z / Ctrl+Y。
  • 登录/同步：输入凭据号登录，云端同步（需配置后端）；分享可选择「只读」或「完全」链接（完全链接会让对方直接登录你的账号，可修改）。
  • 日历调度：📅 进入，点任务→点日期调度；点类别/项目名或 Ctrl 多选→点日期按「一天几个」顺延；未选任务时点某日→点列表空白或「清空该日」按钮可取消该日全部任务。
  • 重置默认 / 导入导出 / 深浅色 / 后台(🔧)。
